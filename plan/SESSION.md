# SESSION — M3: CLIP

Взято из `plan/BACKLOG.md` § M3. Состояние: готово (см. `plan/STATUS.md`).

## Что сделано

| Шаг | Файл | Суть |
|---|---|---|
| 1 | `src/derive.rs` | `clip_input`: центр-кроп превью, 224×224, нормализация CLIP, CHW |
| 2 | `src/db.rs` | `embeddings(file_id, model, sha256, dim, vec)`; триггер инвалидации при смене sha256; `load/save`, `tags` |
| 3 | `src/embed.rs` | `ort` + `tokenizers`: ViT-B/32 int8 + мультиязычный текст + Dense 768→512; теги, cosine, k-means, отчёт |
| 4 | `src/main.rs` | `embed`, `search --repeat` (замер), `clusters` |
| 5 | `src/app.rs` | строка смыслового поиска, фильтр по тегу, тег в карточке, кнопка «Посчитать теги» с прогрессом |
| 6 | `scripts/fetch-model.sh` | ручное скачивание весов с закреплёнными URL и sha256 |

## Критерии приёмки

1. ONNX CLIP ViT-B/32 + мультиязычный текст на CPU, веса 218 МиБ, sha256 проверяется — да.
2. Векторы f32 в БД, повторный `embed` пропускает по sha256 — да (0.025 с на 1971 фото).
3. Поиск < 200 мс на 20 тыс. — да (48–51 мс).
4. 7 русских промптов дают теги; видны в карточке и фильтре — да.
5. k-means 30 кластеров, отчёт `plan/M3-clusters.md` (локальный, в git не идёт) — да.
6. Замеры в `docs/ARCHITECTURE.md` — да.

Ограничения: теги приблизительны, у 849 фото «не уверен»; модель требует AVX2; отчёт с путями
архива не коммитится.
