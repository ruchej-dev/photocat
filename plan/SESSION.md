# SESSION — M2: интерактив по дублям

Взято из `plan/BACKLOG.md` § M2. Состояние: готово (см. `plan/STATUS.md`).

## Цель

Из отчёта «вот 103 группы» получить решение: что оставить, что помечено лишним, и почему.
Оригиналы не трогаются — решение живёт только в БД и в экспортируемом плане.

## Что делаем

| Шаг | Файл | Суть |
|---|---|---|
| 1 | `src/derive.rs` | `sharpness()` — дисперсия лапласиана по серому; считается при индексации из того же декода |
| 2 | `src/db.rs` | `ALTER TABLE files ADD COLUMN sharpness REAL`, `decision TEXT`; `mark_keep`; решения переживают переиндексацию, если sha256 не менялся |
| 3 | `src/dupes.rs` | в `Group` — совет (`suggested`, `advice`), сводка (`summary`), экспорт плана (`plan_csv`) |
| 4 | `src/app.rs` | в виде «Дубли» — кнопка «оставить» на плитке, пометка «лишний», счётчик, «Экспорт плана», «Скопировать список в буфер» |
| 5 | `src/main.rs` | `dupes --csv` печатает `decision` и `sharpness`; `--plan FILE` — план |
| 6 | docs | `ARCHITECTURE.md` (схема, замеры), `UI.md` (вид «Дубли»), `DECISIONS.md` (ADR 0012) |

## Критерии приёмки (из BACKLOG)

1. Кнопка «оставить» по одному файлу на группу, остальные — лишние; состояние в БД, переживает перезапуск.
2. Совет по группе: резкость, разрешение, размер; подписан словами.
3. «Экспорт плана» → CSV `group,keep_path,drop_path,reason,wasted_bytes`; отдельно — копирование в буфер.
4. Счётчик: «в группах N, помечено лишними M, освободится X» — пересчитывается на лету.
5. `photocat dupes --csv` печатает `decision` и `sharpness`.
6. Замер на корпусе 2230 файлов записан в `docs/ARCHITECTURE.md`.
