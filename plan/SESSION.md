## Критерии приёмки

1. SCRFD + ArcFace ONNX, выравнивание по 5 точкам, кластеры, подписи вручную — да.
2. Порог в настройках (0.45 по умолчанию), ложные склейки видны кропами и разъединяются «не он» — да.
3. Наружу не уходит ни лицо, ни эмбеддинг, ни путь; модель скачивается только по согласию с sha256 — да.

## Замеры на корпусе

- `faces --jobs 4 --threshold 0.45`: 630.2 с (0.32 с/снимок), 1972/1972 снимков (1 ошибка — известный битый
  JPEG, помечен как 0 лиц), 2498 лиц на 856 снимках, 617 групп, БД 11.1 → 22 МБ, кропы 11 МБ.
- `faces --recluster --threshold 0.45`: 1.2 с.
- Порог 0.40 / 0.50 / 0.60: 534 / 710 / 1006 групп.
- `faces download --yes`: 182.4 МиБ за 31.3 с, sha256 обоих файлов совпал.
- Кропы проверены глазами: выравнивание верное; крупные группы — один и тот же человек.

## Ограничения

- 617 групп без имён: назвать своих людей — работа владельца глазами.
- Порог не спасает от склейки похожих родственников; «не он» разъединяет и переживает пересборку.
- Детектор принимает за лицо экран/статую/картинку; такие группы остаются отдельными.
- Кропы подменённых файлов остаются в кэше (ключ — sha256): код не удаляет файлы даже в кэше.
